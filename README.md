# Respire IA — Prototype de Prévention de l'Épuisement Professionnel

**Respire IA** est un assistant numérique de prévention précoce et d'accompagnement face à la surcharge mentale au travail. Ce dépôt contient le prototype fonctionnel Front-End optimisé pour les interfaces mobiles (iPhone / Android).

## 🚀 Fonctionnalités Clés du Prototype
- **📊 Module de Check-in (CBI) :** Questionnaire rapide auto-évaluatif calculant la jauge d'énergie en temps réel.
- **🧘 Cohérence Cardiaque :** Guide respiratoire animé (Protocole clinique de transition 5s / 5s).
- **📝 Journal de Clôture avec Intercepteur :** Analyse lexicale locale instantanée. Si des expressions liées à une urgence ou une détresse psychologique aiguë sont détectées, l'application s'interrompt pour afficher les numéros nationaux d'aide (**3114**, **15**, **112**).

## 🛡️ Cadrage Réglementaire & Sécurité (Cahier des charges de production)
Pour un déploiement industriel, l'application est configurée pour respecter les exigences e-santé françaises :
1. **Conformité HDS :** Migration obligatoire vers un stockage cloud agréé Hébergeur de Données de Santé.
2. **Gouvernance RGPD/CNIL :** Recueil du consentement exprès par Opt-In (Article 9.2.a du RGPD pour les données sensibles) et étanchéité absolue vis-à-vis des services RH et des employeurs.

## 🛠️ Installation et Déploiement Local
Ce dépôt est un projet statique autonome. Pour le tester :
1. Clonez le projet : `git clone https://github.com`
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur mobile ou de bureau.
